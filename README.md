# ⚖️ NyayaNode: Basic Legal Matrix API

This project provides a mock API backend and UI concept for a legal tech platform, demonstrating concepts like statutory cross-conversion and evidence certification in an in-memory test environment.

## Features

- **Statutory Matrix API (`engine/nyayaTopologyService.js`)**: An in-memory CRUD service providing static mock data for statutory codes and precedents.
- **Mock Dashboards**: HTML/CSS/JS frontend showcasing UI concepts for FIR Reasoning and Smart Contract Auditing.
- **Basic Hashing Utility**: Simple crypto hashing script for the "Evidence Vault" concept.
- **Automated Tests**: Basic Node.js tests verifying the in-memory array manipulation functions.

## 🚀 Quickstart

```bash
npm install

# Run automated tests
node --test tests/enterpriseMesh.test.js

# Start server
node server.js
# Open http://localhost:5030
```
